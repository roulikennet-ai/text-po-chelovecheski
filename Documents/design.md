# design.md — «Текст по-человечески»

**Версия:** 1.0 · **Дата:** 23.11.2026
**Область действия:** визуальный язык, дизайн-токены, компоненты, layout экранов E1–E11 и M1–M5, состояния S1–S19, адаптивность, иконки/иллюстрации, доступность.
**Документ нормативный:** реализация фронтенда обязана использовать токены из §2–§4 и компоненты из §5 без самостоятельных отступов и цветов (§12 ТЗ: «приложение строго следует design.md»).

> Источник требований: `tz-1-trebovaniya.md` (§1–§7) + `tz-2-realizaciya.md` (§8–§13). Ссылки вида `FR-x`, `E1`, `S1`, `A1`, `B1`, `§11.3` — из ТЗ.
> Платформа по ТЗ: **Windows, .exe, Tauri + React + TypeScript**, целевое железо — офисный ноутбук (CPU, 8–16 ГБ RAM), мин. разрешение 1366×768. Мобильной версии нет (§9.1) — есть адаптивность десктопного окна (§9.2).
> Учебная веб-версия на Flask/GigaChat из старых копий материалов целевым не является.

---

## 1. Визуальная концепция

**Идея:** «рабочий стол редактора научного текста». Экран должен ощущаться как чистый лист бумаги с полями, а не как dashboard: минимум хрома, максимум воздуха, спокойная тёплая нейтральная база и один тёплый акцент.

**Пять принципов (проверяемые):**

| # | Принцип | Как проверяется |
|---|---|---|
| P1 | **Крупная читаемая типографика** | текст документа ≥ 16 px, межстрочный ≥ 1.5 (A3, FR-11.1); UI-текст ≥ 14 px |
| P2 | **Большие заметные кнопки** | все действия ≥ 44 px по высоте, зона клика ≥ 32×32 (§9.2); главное действие — единственная filled-кнопка на экране |
| P3 | **Одна измерительная сетка** | только шкала отступов §4; в коде запрещены числа, не входящие в шкалу |
| P4 | **Блоки разделены воздухом, а не рамками** | сначала увеличение отступа, только потом hairline-граница; тень — только у «плавающих» слоёв (модалка, тост, дропдаун) |
| P5 | **Ограниченная палитра** | 3 базовых цвета (§2.1) + 3 семантических статуса (§2.3), не смешивать роли |

**Чего в интерфейсе нет:** декоративных градиентов, «стеклянных» blur-панелей, теней у всех подряд, анимаций внимания (пульсация/мигание), иллюстраций внутри области текста, emoji как иконок статуса в лентах и таблицах (см. §7 — статус = цвет + текст + иконка).

## 2. Цветовая система

### 2.1. Три базовых цвета

| Токен | HEX | Роль |
|---|---|---|
| `--ink` | `#1F2A38` | Тёмный сине-графитовый. Весь текст, иконки, активные состояния, граница «ink» |
| `--accent` | `#B4531F` | Терракота (жжённая сиена). Единственный «живой» цвет: главное действие, фокус, ссылка, выбранное состояние, текущий абзац |
| `--paper` | `#F7F5F1` | Тёплая бумага. Фон приложения (окно, лента, панель) |

Акцент выбран не «кнопочно-синим», а тёплым терракотовым: он перекликается с печатной правкой на бумаге и не конкурирует с зелёным/жёлтым/красным статусами.

### 2.2. Производные (оттенки базовых — новых имён цветов не вводим)

| Токен | Значение | Откуда | Применение |
|---|---|---|---|
| `--surface` | `#FFFFFF` | paper → 0 % ink | «лист» документа, карточка, поле ввода |
| `--surface-sunken` | `#EFEDE7` | paper + 6 % ink | фон ленты-групп, track ползунка, zebra-строки таблицы |
| `--line` | `#DCD8D0` | paper + 15 % ink | hairline-границы блоков (1 px) |
| `--line-strong` | `#B9B3A8` | paper + 30 % ink | границы полей, раздвиг колонок |
| `--muted` | `#5C6672` | ink @ 68 % | вторичный текст, подписи, счётчики |
| `--muted-soft` | `#8A93A0` | ink @ 45 % | плейсхолдеры, disabled-текст |
| `--ink-tint-08` | `rgba(31,42,56,.08)` | ink @ 8 % | hover нейтральных поверхностей |
| `--accent-08` | `#F6EAE1` | accent @ 10 % | фон выбранного пресета/строки |
| `--accent-16` | `#EEDACB` | accent @ 20 % | hover accent, track заполнение |
| `--accent-strong` | `#93401A` | accent −18 % | active/нажатие accent |

### 2.3. Семантические статусы (только §E5/E4/S-состояния)

Используются **исключительно** для statuses 🟢/🟡/🔴 и прогресса. Запрещено красить ими кнопки, заголовки, панели.

| Токен | HEX (текст/иконка) | HEX (фон) | Значение |
|---|---|---|---|
| `--ok` | `#2E7D4F` | `#E7F1EA` | 🟢 полностью сохранён / успех |
| `--warn` | `#A65A00` | `#FBF0DF` | 🟡 требует внимания |
| `--bad` | `#B3261E` | `#FBE9E7` | 🔴 потеряна единица данных / ошибка |

Третий канал (не только цвет — требование доступности §10): каждый статус = **цвет + подпись словом + иконка** (`check` / `alert-triangle` / `x-octagon`).

### 2.4. Подсветка правок (ключевой визуальный механизм E4)

Разные роли не должны путаться с цветовой «светофорной» схемой, поэтому используются **маркерные** (tint) фоны, а не сплошные цвета, и разные формы пометки:

| Что | Фон | Текст/декор | Комментарий |
|---|---|---|---|
| Изменённый фрагмент в «стало» | `--mark-added` `#EAF3E9` | без подчёркивания | мягкий зелёный маркер |
| Удалённый фрагмент в «было» | `--mark-removed` `#F6E1DE` | `text-decoration: line-through`, цвет `--muted` | красный маркер + зачёркивание |
| Защищённый фрагмент (авто) | `--mark-protected` `#F0EFEA` | пунктирное подчёркивание 1 px `--line-strong` | «неприкосновенно» |
| Защищённый вручную / из словаря | тот же фон + левая метка 2 px `--accent` | — | визуально отличается от авто |
| Токен-заглушка `⟦Ч12⟧` | `--surface-sunken` | моно `--muted`, скругление 3 px | видно только в отладочном виде (§5.13) |
| Текущий абзац | левая полоса 3 px `--accent` | — | без изменения фона текста |
| 🔴 абзац в списке | фон `--bad-bg`, левая полоса 3 px `--bad` | — | — |

Все маркеры — **только фон**, никогда `color` самого текста: смысл текста читается без помех.

## 3. Типографика

### 3.1. Два шрифта (максимум по требованию)

| Роль | Шрифт | Лицензия | Начертания | Почему |
|---|---|---|---|---|
| **Интерфейс** | `Inter` (fallback: системный `Segoe UI`) | SIL OFL 1.1 | Regular 400, Medium 500, Semibold 600 | отличная кириллица, нейтральный гуманистский гротеск, хорошо держит 11–14 px |
| **Документ** | `Literata` (fallback: Georgia) | SIL OFL 1.1 | Regular 400, Italic 400, Semibold 600 | экранный serif, рассчитан на длинное чтение, кириллица; визуально отделяет «текст автора» от «текста интерфейса» |

Третий шрифт (`--font-mono`) — служебный, только для токенов-заглушек, хэшей в журнале и чисел в статус-баре; в иерархии дизайна шрифтом интерфейса не считается. Если критично «ровно два» — mono заменяется на `font-variant-numeric: tabular-nums` в Inter.

**Бандл и офлайн (FR-8.3, §8.1):** шрифты поставляются внутри `.exe` как `.woff2` с подсетом (кириллица + латиница + знаки препинания + `⟦ ⟧`). Никаких `@import`, CDN и Google Fonts — приложение обязано работать без интернета (B5). Подсет ≈ 45–70 КБ на файл.

### 3.2. Иерархия

| Стиль | Размер / line-height | Вес | Где |
|---|---|---|---|
| `display` | 30 / 1.2 | 600 | заголовок пустого состояния, заголовок модалки |
| `h1` | 24 / 1.3 | 600 | заголовок экрана (E5, E7, E11) |
| `h2` | 18 / 1.35 | 600 | заголовок блока/секции |
| `body-ui` | 14 / 1.45 | 400 | базовый интерфейс, подписи, таблицы |
| `label` | 12 / 1.3, `letter-spacing: .02em` | 500, `--muted` | заголовки групп ленты, подписи полей, колонки таблиц |
| `meta` | 11 / 1.3 | 400, `--muted` | статус-бар, счётчики, таймстемпы |
| `doc` | `--doc-size` / `--doc-leading` | 400 | текст документа |
| `doc-h1..h3` | 1.6 / 1.35 / 1.2 × от `--doc-size` | 600 | распознаваемые заголовки DOCX |

**Правила документа (P1, A3):**
- Минимум 16 px, по умолчанию 17 px (≈ 12.75 pt), максимум 24 px — шаг 1 px, регулируется в «Вид» (FR-11.1).
- Межстрочный **1.65** — комфортный интервал между строками; не менять на «плотный» нигде, кроме таблиц.
- Абзацный отступ: `margin-bottom: 1em` (не красная строка — редактор, а не печать).
- Ширина колонки текста — `--doc-max-w` (720 px) и **не** растягивается на всю ширину окна: длинная строка убивает читаемость.
- `text-wrap: pretty`, `hyphens: auto` (рус.), `font-variant-numeric: tabular-nums` для чисел в счётчиках и таблицах.
- Выделение: стандартное `::selection { background: var(--accent-hover); }`.

## 4. Сетка, отступы, ритм

### 4.1. Базовая единица

База **4 px**. Разрешены только значения шкалы `--s-1…--s-9`. Правило выбора:

| Ситуация | Отступ |
|---|---|
| Внутри компонента (иконка↔подпись, подпись↔значение) | 4–8 |
| Между элементами одной группы | 12 |
| Между группами ленты / между полями формы | 16–24 |
| Между блоками экрана (секция↔секция) | 32 |
| Вокруг пустого состояния / крупного заголовка | 48–64 |
| Воздух в пустом экране (S1, S16) | до 96 |

**Единый паддинг поверхностей:** карточка/панель/ячейка таблицы — `16`; модалка — `32`; экран-состояние — `48`. Никаких «своих» чисел.

### 4.2. Каркас окна (E1)

```
┌──────────────────────────────────────────────────────────────────────┐
│ ЛЕНТА (высота 96, фон --paper, низ: 1px --line)                      │
│ [Файл] │ Импорт/Экспорт │ Обработка │ Правки │ Защита │ Вид │ Проект │
├────────────┬────────────────────────────────────────────────┬────────┤
│ ПАНЕЛЬ     │  ОБЛАСТЬ ДОКУМЕНТА                             │        │
│ 320 px     │  фон --paper; «лист» --surface по центру       │        │
│ --paper    │  макс. 720 px, паддинг 48/64                   │        │
│ 1px --line │                                                │        │
├────────────┴────────────────────────────────────────────────┴────────┤
│ СТАТУС-БАР (32 px, --surface-sunken, --fs-12 --muted)                │
└──────────────────────────────────────────────────────────────────────┘
```

- Лента и панель — **одна** нейтральная поверхность (`--paper`), не «серые блоки с рамками»: разделение — hairline `--line`.
- «Лист» документа — белая карточка `--surface` с `--sh-1` и радиусом `--r-3`, плавающая на тёплом фоне. Это главный визуальный якорь «бумаги».
- Вертикальный ритм: все секции кратны 8 px; внутренний паддинг листа — `48` сверху/снизу, `64` слева/справа (на 1366 — `32`).

### 4.3. Сетка E4 «было/стало»

```
┌─────────────── было (1fr) ───────────┬─┬─────────────── стало (1fr) ─────────┐
│                                        │ │                                     │
│  абзац №12   🟡 требует внимания       │ │  абзац №12                          │
│  [исходный текст, serif, маркеры]      │ │  [результат, serif, маркеры]         │
│                                        │ │                                     │
│            Принять · Отклонить · Другой вариант                                 │
└────────────────────────────────────────┴─┴─────────────────────────────────────┘
                                   gutter 32
```

- `grid-template-columns: 1fr 32px 1fr`, колонки — **белые листы** с паддингом 24.
- Центральный канал 32 px — «перемычка»: номер абзаца, статус, действия. Клик по фрагменту в правой колонке подсвечивает соответствующий левый (`--hover-neutral` + левая полоса 3 px `--accent`) — A8.
- Синхронная прокрутка по абзацам, а не по пикселям: якорь — верх текущего абзаца.

## 5. Компоненты

> Реализация: `src/components/ui/*`. Каждый компонент принимает только токены; магические числа в JSX запрещены (проверка §11.4 чек-листа дизайна).

### 5.1. Кнопки

| Вариант | Когда | Фон | Текст | Граница | Радиус | Высота | Мин. паддинг-x |
|---|---|---|---|---|---|---|---|
| **Primary** (filled accent) | единственное главное действие экрана: «Запустить», «Принять», «Скачать DOCX» | `--accent` (hover `--accent-hover`+ink-текст при потере контраста → использовать `--accent-active` и белый текст) | `#FFFFFF` | — | `--r-2` | 44 (lg 48) | 20 |
| **Secondary** (outline) | второстепенное: «Отклонить», «Отмена», «Повторить» | `--surface` | `--ink` | 1 px `--line-strong` | `--r-2` | 40 | 16 |
| **Ghost / flat** | действия в ленте и тулбаре | transparent | `--ink` | — | `--r-2` | 40 | 12 |
| **Danger** | редкие необратимые: «Очистить журнал», «Сбросить профиль» | `--surface` | `--bad` | 1 px `--bad` | `--r-2` | 40 | 16 |
| **Icon-only** | лента, ячейки таблиц | transparent | `--ink` | — | `--r-2` | 36×36 | — |

Состояния (для всех): `hover` — фон `--hover-neutral` / `--accent-hover`; `active` — сдвиг вниз на 1 px (`translateY(1px)`), без изменения цвета; `focus-visible` — кольцо `2px --accent`, `offset 2px` (обязательно, §10); `disabled` — opacity .45, `cursor: not-allowed`, текст `--muted-soft`.

**Правила «больших кнопок»:**
- На экране ровно **одна** Primary. «Принять всё» и «Отклонить всё» в ленте — Ghost с иконкой; Primary остаётся за «Запустить».
- Подпись — глагол + существительное, с заглавной буквы, без точки: `Запустить обработку`, `Скачать DOCX`, `Открыть отчёт смысла`.
- Иконка слева, 18 px, gap 8.
- Ширина в ленте — по содержимому, мин. зона клика 32×32 (§9.2).

### 5.2. Лента (Ribbon, верх E1)

- Высота 96 px: строка групп (40 px) + подписи групп (20 px) + hairline.
- Группа = вертикальный стек: `[иконки/кнопки]` + `label`-подпись снизу (`--fs-12 --muted`),隔开 группы — вертикальная hairline `--line` + отступ 16.
- Порядок групп строго по ТЗ: **Импорт/Экспорт · Обработка · Правки · Защита · Вид · Проект**.
- Активная группа — ничего не «подсвечивается»; текущее значение состояния показывается внутри группы (см. 5.3/5.4).
- При ширине < 1200 px лента сворачивается в 2 ряда с компактными подписями (только иконки + tooltip с названием).

### 5.3. Пресеты подачи F1–F4 (сегменты-карточки, E3)

Четыре карточки в один столбец (панель слева) — не `<select>`: выбор должен быть виден постоянно.

```
┌───────────────────────────────────────┐
│ F1  Научный, но читаемый          ✓  │  ← выбранная: фон --accent-soft,
├───────────────────────────────────────┤     граница 1px --accent, галка --accent
│ F2  Сжатый                −15% −30% −50%│  ← чипы целевого сжатия (F2) в той же карточке
│ F3  Развёрнутая проза вместо списков  │
│ F4  Для журнала                       │
└───────────────────────────────────────┘
```

- Высота карточки 48, паддинг-x 12, радиус `--r-2`, gap между карточками 8.
- Код `F1…F4` — `--fs-12 --muted` (моноширинный вид не нужен), название — `--fs-14 --ink` 500.
- Одна строка описания под названием — `--fs-12 --muted`, максимум 48 px шириной текста (обрезка `…`).
- Выбор одного пресета на запуск (FR-1.1) визуально подчёркнут: выбрана всегда ровно одна карточка.

### 5.4. Ползунок интенсивности 1–5

- Дискретный, 5 позиций, `step=1`, track 4 px `--surface-sunken`, заполнение `--accent`, thumb 20 px круг `--surface` с границей 2 px `--accent` и `--sh-1`.
- Под track — 5 подписей: `1 косметика · 2 лёгкая · 3 базовая · 4 смелая · 5 пересказ` (`--fs-11 --muted-soft`), активная — `--ink` 500.

- Уровень 5: при выборе открывается модалка подтверждения с примером отличия от 4 (FR-2.3) — ползунок остаётся на 4 до подтверждения.

### 5.5. Поля ввода, поиск, выпадающие

### 5.8. Прогресс

- Пакетная обработка: линейный bar 6 px, track `--surface-sunken`, заполнение `--accent`, скругление `--r-full`; подпись `37 из 84 абзаца · осталось ~2 мин 10 с` (`--fs-12 --muted`).

## 6. Экраны: компоновка и содержание

### E1 — Редактор (главный)
Каркас §4.2. Стартовое состояние — **пустой редактор с плейсхолдером и двумя кнопками** (S1, ТЗ §4.2): на белом листе по центру иллюстрация (см. §8), заголовок `Вставьте текст или импортируйте DOCX`, две кнопки: `Вставить из буфера` (Primary) и `Импорт DOCX` (Secondary). Никакого списка проектов на старте.

### E3 — Панель слева (часть E1)
Порядок сверху вниз, секции разделены hairline + 24:
1. Пресет подачи (5.3)
2. Ползунок интенсивности (5.4)
3. Счётчик знаков/страниц (крупные числа `--fs-20 600`)
4. Защищённые фрагменты — сворачиваемый список (5.6), шапка с суммарным чипом
5. Статус движка (чип `Облако`/`Локально` + кнопка переключения)
6. Прогресс обработки (5.8)

### E4 — Сравнение
См. §4.3. Доп: «Только результат» скрывает левую колонку; при < 900 px — вкладки `Исходник` / `Результат` (§9.2).

### E5 — Отчёт проверки смысла
Заголовок + сводка-числа сверху (не снизу — автор должен увидеть результат до таблицы), затем таблица §5.7, затем блок 🔴-строк с действиями (S11: `Исправить вручную` / `Принять осознанно` / `Повторить абзац`). Экспорт блокируется, пока есть 🔴 без подтверждения (FR-7.5).

### E6 — Защищённые фрагменты
Три секции-карточки (Авто / Ручная / Словарь проекта), в каждой: чипы фрагментов + переключатель класса + счётчик. Снятие авто-защиты → подтверждение с конкретным значением: «Вы разрешаете изменить число 12,4?» (FR-3.3).

### E7 — Профиль стиля
Пустое состояние S16 (иллюстрация + «Загрузите ещё 3 ваших текста, чтобы я писал вашими словами»). Заполненное: 5 метрик ритма как «спидометры-числа» + облако топ-200 слов-маркеров (чипы, размер чипа ∝ частоте, один цвет `--ink` с opacity) + список оборотов + 3 кнопки (`Пересчитать`, `Экспорт профиля`, `Сбросить профиль` — последняя Danger).

### E8 — История проекта / версии
Список-мастер: слева версии (дата/время, снимок-причина `запуск`/`экспорт`/`откат`), справа предпросмотр diff с текущей. Пустое состояние — иллюстрация + текст.

### E9 — Экспорт
Карточки формата: `DOCX с исходным форматированием` (список сохранённого: шрифты, отступы, интервалы, нумерация, колонтитулы, сноски, разрывы), `Чистый текст`, `Markdown`. Чекбокс «включить служебные метки» **отсутствует** по FR-9.5. При 🔴 — баннер перед кнопкой `Скачать`.

### E10 — Настройки
Секции: Движок (облако/локально, выбор модели, путь к GGUF, полный запрет облака) · Ключ API (маска `••••••4f2a`, кнопка «Проверить») · Лимиты (недельная нагрузка, объём запуска) · Пути (каталог данных) · Шрифт документа (слайдер 16–24 + предпросмотр). Все переключатели — подписаны, danger-действия подтвердились модалкой.

### E11 — Журнал действий
Таблица `время | событие | объект | движок | параметр | результат`, фильтры по событию/движку, кнопки `Экспорт журнала`, `Очистить` (Danger). Визуально — только метаданные и хэши (FR-SEC-4): в колонке «объект» показывается `абзац #23 · sha1:9f2c…`, никакого текста.

## 10. Доступность и обратимость

- **Контраст** (проверено на паре `--surface`): `--ink` 13.5:1, `--muted` 5.8:1, `--accent` текст 5.0:1, белый на `--accent` 5.0:1, `--ok` 5.1:1, `--warn` 5.1:1, `--bad` 6.6:1 — все ≥ 4.5:1 (AA). Границы и иконки ≥ 3:1.
- **Не только цвет:** статус = иконка + слово; удалённый текст = зачёркивание; добавленный = фон; защита = пунктир.
- **Фокус:** `:focus-visible` кольцо `2px --accent`, `outline-offset: 2px` на всех интерактивных; порядок обхода — лента → панель → документ → статус-бар.
- **Клавиатура (FR + §9.2):** `Ctrl+Z`, `Ctrl+S`, `Ctrl+F`, `Ctrl+Enter` (запуск), `Ctrl+Y` (принять), `Ctrl+Shift+Y` (принять всё), `Esc` (модалка/панель вариантов), `Tab`/`Shift+Tab`, `↑/↓` — переход по абзацам в E4. Все горячие клавиши показаны в подсказках (tooltip с `<kbd>`-стилем: `--surface-sunken`, радиус 3, `--fs-11 --muted`).
- **AOM:** документ — `role="textbox" aria-multiline="true"`; абзацы — `aria-label="Абзац 12, статус: требует внимания"`; таблицы — `<th scope="col">`; модалки — `aria-modal`, ловушка фокуса; прогресс — `role="progressbar"` + `aria-valuetext="37 из 84 абзаца"`.
- **Движение:** `@media (prefers-reduced-motion: reduce)` — все transition = 0; shimmer запрещён глобально (§5.8).
- **Откат:** любое принятое правка обратима (Ctrl+Z, FR-10.3) — визуально это отражено в статус-баре счётчиком «принято/отклонено», а не «уничтожено».

## 11. Движение (motion)

| Что | Как |
|---|---|
| Hover кнопок/строк | `background var(--dur-1) var(--ease)` |
| Открытие панели вариантов | `opacity` + `translateY(4px → 0)`, `--dur-2` |
| Модалки | оверлей `opacity --dur-2`, окно `scale .98 → 1` + `--dur-3` |
| Тосты | `translateY(8px → 0)` + opacity, `--dur-2` |
| Прогресс | ширина bar: `transition width --dur-3 linear` (без «догоняющей» пружины) |
| Смена абзаца в E4 | без анимации; только мгновенная прокрутка (`scroll-behavior: smooth`) |

Никаких анимаций «привлечения внимания», параллакса, ленивых fade-in контента документа (текст должен появляться сразу — норматив отклика UI ≤ 100 мс, §8.4).

## 12. Экспорт, печать и служебное

- В DOCX/TXT/Markdown попадают **только** текстовые содержимые; подсветка правок, статусы, чипы и иллюстрации не экспортируются (FR-9.5).
- Предпросмотр экспорта в E9 показывает документ в режиме «Только результат» (без маркеров) — визуальное обещание «что уйдёт в Word».
- Стиль листа в предпросмотре не влияет на DOCX: шрифты/отступы Word сохраняются из оригинала (FR-9.2, B2).
- Тёмная тема **вне объёма MVP**: ТЗ требует светлый академичный стиль (A3). Токены уже собраны в `:root` — тема добавляется одним слоем переопределений (этап 2), без правок компонентов.
