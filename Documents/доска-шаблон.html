Что сделано

Учёт запросов и токенов

Каждый запрос к GigaChat пишет метрику: модель, prompt/completion/total токены, время ответа, успех или код ошибки, длина текста в символах.

  • Не сохраняется: текст документа, промпты, ответы модели
  • Запись атомарная (temp + rename), файл app/data/metrics.json
  • Проверено на реальном запросе: 87 / 75 / 162 токена

Админ-сводка

Страница /admin и API /api/admin/stats?days=7 за Bearer-токеном из ADMIN_TOKEN.

  • Карточки: запросы, успешно, ошибки, токены
  • Разбивка по моделям и последние 20 запросов
  • Без токена — 401; без настройки — 503

Интеграция с ВК

Серверный модуль server/vk.mjs: статистика сообщества и Callback API.

  • Подписчики, просмотры, охват за неделю
  • Callback: подтверждение сервера и проверка секрета
  • Без токена блок показывает «Не подключено», приложение работает

Деплой

Готовы Dockerfile, docker-compose.yml, .env.deploy.example, инструкция DEPLOY.md.

  • Многоэтапная сборка, непривилегированный запуск, healthcheck
  • Метрики в томе tph-data
  • Вариант без Docker: systemd

Основной сценарий

Проверен вживую: вставка текста → защита → облако → GigaChat → сравнение «было/стало».

  • Защищено 8 фрагментов: 4 числа, 1 имя, 1 аббревиатура, 2 источника
  • После переписывания все числа и ссылки на месте
  • 0 ошибок в консоли

Исправленные ошибки

По ходу проверки найдено и исправлено:

  • Утечка ключа: в .env.example лежал настоящий ключ GigaChat — заменён на пустое поле
  • Ложная ошибка API: поле ok перезаписывалось числом успешных запросов; теперь okCount / errorCount
  • В предупреждении M1 значился gpt-4o-mini вместо GigaChat
  • В плитке «Облако» — только имя модели без провайдера
  • API/ с ключом не был в .gitignore

Ограничения и что нужно от вас

Публикация на сервере

Нет доступа к серверу, домену и DNS, Docker на машине не установлен. Прод-сборка и админка проверены локально, Docker-образ не собирался.

Нужно: VPS с Docker (или Node 20+), домен для HTTPS, доступ по SSH.

Сообщество ВКонтакте

Нет токена сообщества и его ID. Код готов, но реальный VK API не вызывался — проверены только обработка ошибок и Callback с фиктивным токеном.

Нужно: токен с правами groups, stats; ID сообщества; строка подтверждения Callback API.

Регистрация и вход

В приложении нет аккаунтов: проекты лежат в localStorage. ТЗ требует имя, телефон и пароль, но это отдельный объём работы (серверная БД, сессии, хеширование).

Решение: не реализовывал, чтобы не выдавать неготовое за готовое.

Прочее

Ограничения из прошлых этапов остаются: F3 не подключён в пайплайне, SQLite вместо localStorage, недельный лимит без жёсткой блокировки, профиль стиля не передаётся как few-shot.
